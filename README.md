# SwitchOn
---
SwitchOn은 Spring Framework로 개발된 스케줄 알람 프로젝트입니다
## 프로젝트 개요
---
이 알람 프로그램은 4주 간 진행하는 식사 및 단식 시간을 알려주는 목적으로 제작되었습니다. 주요 기능은 다음과 같습니다
- 로그인을 통한 개인별 저장 기능
- 스케줄 생성으로 기본 형식 제공
- 카카오 로그인을 통한 식사 시간 알람 제공
## 버전 히스토리
---
### Version 1
- 로그인을 통한 개인별 저장 기능
- 스케줄 생성으로 기본 형식 제공
- 체중 기록
- 보충제 및 저탄수 도시락 추천
### Version 2
- 카카오 로그인 & 로그아웃
- 카카오 메시지를 통한 알람
